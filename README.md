# SigSprint

A free study app for the PTCB Pharmacy Technician Certification Exam (PTCE), for iOS and Android.

Not affiliated with or endorsed by PTCB. Study material only, not medical advice.

## Run it

```bash
npm install
npx expo start
```

Scan the QR code with the Expo Go app, or press `w` for the web preview.

## Checks

```bash
npm run lint && npm run typecheck && npm test
```

Project rules are in `CLAUDE.md`.
